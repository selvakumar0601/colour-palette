# 🎨 Color Palette Generator

A simple and interactive **Color Palette Generator** built using HTML, CSS, and JavaScript.

The application generates a random set of 5 HEX color swatches. Users can click on any color to copy its HEX code directly to the clipboard.

## 📌 Features

- 🎨 Generate 5 random colors
- 🔢 Display HEX color codes
- 📋 Click any color to copy its HEX code
- ✅ Shows a copy confirmation message
- 🔄 Generate a new palette anytime
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- 🖥️ Works on desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Clipboard API
- Math.random()
